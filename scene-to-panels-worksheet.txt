4. DIALOGUE AND CONTINUITY REVIEW
[ ] Each line has an identified speaker; silent panels say 'no dialogue'.
[ ] Bubble order follows the intended reading direction.
[ ] Lines fit the chosen layout when viewed at the intended reading size.
[ ] Dialogue does not repeat an action already clear from the drawing.
[ ] Faces, identity anchors, and outfits match, unless a change is explained.
[ ] Prop moves have a visible action or an understandable transition.
[ ] Left/right references name the character's side or the viewer's side.
[ ] Characters react only to information they have learned.
[ ] The final panel shows the intended change from the opening.

5. EXPORT AND READABILITY CHECKLIST (AFTER MAKING THE COMIC)
Target destination and its current requirements: [ ]
Chosen image size / file type / reading order: [ ]
[ ] Open the exported file, not just the editor preview.
[ ] Check every panel and bubble in order at the intended display size.
[ ] Text is legible; contrast and balloon tails make speakers identifiable.
[ ] No text, faces, or important props are cut off at edges or crop boundaries.
[ ] Names and spelling agree with the continuity sheet.
[ ] Provide a text transcript in reading order when sharing the comic.
[ ] Add meaningful image descriptions where the destination supports them;
    describe actions and speakers rather than relying only on color.
[ ] Verify rights and any credits needed for added fonts, art, or source text.
[ ] Keep an editable master and name the export with title and revision.
[ ] If printing, inspect a test print; if posting, inspect the uploaded result.
